# Open Source And Commercial Boundary

## Product Strategy

OpenCardHub should use an open-source core plus commercial plugins and optional cloud hosting.

The community edition must be useful enough to attract real users. Commercial value should come from scale, automation, advanced configuration, premium templates, and hosted convenience.

## Recommended License Direction

Recommended direction:

- `AGPL-3.0` for the open-source core.
- Separate commercial license for users who need closed-source modifications or commercial plugin rights.

This should be reviewed before the first public release.

## Community Edition

Community edition should include:

- Main-site product management.
- Product categories.
- Card inventory.
- Basic order system.
- Alipay payment.
- Automatic card delivery.
- V0/V1/V2 levels.
- Configurable level capabilities.
- Basic wholesale discount.
- Basic storefront creation if capability allows it.
- System subdomain storefronts.
- Basic storefront settings.
- Basic templates.
- Basic order and profit statistics.
- Docker Compose deployment.

## Commercial Edition / Plugins

Commercial features may include:

- Custom domain binding.
- Automatic SSL issuance and renewal.
- Premium templates.
- Advanced storefront decoration.
- Advanced pricing rules.
- Advanced notification channels.
- Agent independent payment providers.
- API supply integration.
- Webhooks.
- Advanced analytics.
- Risk control rules.
- Multi-supplier support.
- Plugin marketplace.
- Cloud license management.

## Hosted Cloud Version

Hosted cloud service may include:

- Managed deployment.
- Automatic upgrades.
- Managed database backup.
- Managed domain and SSL.
- Built-in premium templates.
- Built-in commercial plugins.
- Priority support.
- Monthly or annual billing.
- Billing by storefront count, order volume, or feature package.

## Important Boundary Principle

The open-source core should not be artificially broken.

Paid value should focus on:

- Saving time.
- Reducing operations complexity.
- Supporting larger scale.
- Enabling advanced customization.
- Providing professional templates and plugins.

Core storefront and order capabilities should remain usable in the community edition.
